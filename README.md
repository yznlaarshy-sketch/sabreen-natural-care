# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/398f055c-58af-4cef-9bc2-4c72b90dbb29

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Supabase persistence

This project now supports optional Supabase persistence without removing the existing local JSON backup. See `supabase/README_AR.md` and `supabase/schema.sql`.
