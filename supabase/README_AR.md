# ربط موقع صابرين بقاعدة Supabase

هذه النسخة تحافظ على الموقع الحالي كما هو، وتضيف حفظًا دائمًا للبيانات في Supabase.

## ما الذي يحفظه Supabase؟

- المنتجات الثمانية الحالية وكل المنتجات الجديدة
- الطلبات وإيصالات التحويل
- إعدادات المتجر
- بيانات دخول الإدارة وتغييراتها

الملف `data/store_data.json` يبقى داخل المشروع كنسخة احتياطية، ولا يتم حذفه.

## إعداد واحد فقط في Supabase

1. أنشئ مشروعًا مجانيًا في Supabase.
2. افتح **SQL Editor**.
3. افتح الملف `schema.sql` وانسخ محتواه كاملًا.
4. الصقه في SQL Editor واضغط **Run**.
5. من **Project Settings → API** خذ:
   - Project URL
   - `service_role` key

## متغيرات البيئة

ضعهما في الاستضافة التي تشغّل الموقع:

`SUPABASE_URL=رابط مشروعك`

`SUPABASE_SERVICE_ROLE_KEY=مفتاح service_role`

**مهم:** مفتاح `service_role` سري جدًا، ولا يوضع داخل ملفات React أو المتصفح ولا يتم إرساله للزوار.

بعد تشغيل الموقع بهذه المتغيرات، سيقرأ السيرفر البيانات الموجودة في Supabase. إذا كانت قاعدة البيانات فارغة، سيأخذ البيانات الحالية من `data/store_data.json` ويضعها في Supabase تلقائيًا.
